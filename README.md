# ezhukov-site

Резюме и портфолио (Astro + Tailwind). Зависимости и скрипты — через **Bun**.

## Команды

Из корня проекта:

| Команда        | Действие                          |
| -------------- | --------------------------------- |
| `bun install`  | Установка зависимостей            |
| `bun run dev`  | Dev-сервер (обычно `localhost:4321`) |
| `bun run build` | Сборка в `./dist/`               |
| `bun run preview` | Локальный предпросмотр сборки  |

Локфайл: `bun.lockb` (коммитить в репозиторий).
